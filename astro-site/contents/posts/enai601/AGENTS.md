# ENAI601 시리즈 편집 규칙

이 규칙은 ENAI601 시리즈 전체의 기존 글과 새 글에 적용한다.

- 서문은 이 단원이 ENAI601에서 왜 필요한지, 어떤 문제를 해결하며 앞뒤 단원과 어떻게 연결되는지 설명한다.
- 자료를 대조했다는 말, 필기 페이지 목록, 작성·검산·그림 제작 과정, 원고 편집·보충 내역을 서문에 넣지 않는다.
- 출처와 학습 범위·보충 설명의 구분은 글 맨 끝의 참고 자료에 모으고 앞에서 반복하지 않는다.
- 서문에 안내표가 필요하면 필기의 페이지 순서가 아니라 학습할 개념과 질문으로 구성한다.
- 처음 배우는 독자를 가정해 낯선 표기·용어를 설명하고, 구체적인 예와 그림에서 정의식으로 연결한다.
- 글은 독자에게 개념을 설명하는 독립적인 블로그 글로 쓴다. 대화 상대·공동 학습 경험을 전제하거나 “우리가 오래 붙잡았던 질문”, “대화에서 공부한 흐름”처럼 대화 과정을 회고하지 않는다. 질문은 개념상 필요한 이유에서 제시한다.
