# ENAI607 Mega Review

Python 3 with NumPy and Matplotlib. Keep all files together.
Install if needed: python -m pip install numpy matplotlib

python ENAI607_Mega_Review.py
python ENAI607_Mega_Review.py --show
python ENAI607_Mega_Review.py --game
python mini_drills.py
python mini_drills.py --input
python mini_drills.py --exit
python test_mega_review.py

Default main execution has no input prompts and saves the report plus three PNGs
beside the script. --game runs only the game. --show saves before displaying.
The provided-data assertions in main must be updated if lab_readings.txt changes.
Sensor rejects bool readings; Date rejects bool year/month/day values.
create_tuple assumes num is a nonnegative integer.
The Mini M1 insertion raises ValueError; lab_strings.str_insert prints and returns None.
